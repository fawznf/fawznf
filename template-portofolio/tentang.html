Halo! Saya Raihan Fawwaz Naufal, lulusan S1 Teknik Informatika dari Universitas Muhammadiyah Bekasi Karawang dengan minat pada bidang Data Science, Data Analytics, dan teknologi informasi. Saya senang mengolah data mentah menjadi wawasan yang membantu pengambilan keputusan.

Saya berpengalaman dalam pengolahan data, analisis data, dan machine learning melalui proyek akademik serta program MSIB Batch 7 Data Science di PT Mitra Talenta Grup (Celerates), termasuk membangun chatbot berbasis clustering dengan Gemini Developer API. Saya juga pernah melakukan web scraping ulasan layanan publik menggunakan Python untuk analisis sentimen, serta membuat sistem pemantau tingkat kebisingan berbasis ESP32 sebagai tugas akhir.

Saya adaptif, cepat belajar, dan dapat bekerja secara mandiri maupun dalam tim, dengan kemampuan analitis, pemecahan masalah, dan komunikasi yang baik. Saya terus mendalami machine learning, deep learning, NLP, serta pengembangan web dan IoT.
